# 前端项目

一个简单的前端应用框架

## 项目结构

```
/
├── index.html          # 主页面
├── css/
│   └── style.css      # 样式文件
├── js/
│   └── app.js         # JavaScript 逻辑
└── README.md          # 项目说明
```

## 使用方法

直接在浏览器中打开 `index.html` 文件即可查看应用。

## 开发

你可以：
- 在 `index.html` 中添加更多页面结构
- 在 `css/style.css` 中自定义样式
- 在 `js/app.js` 中添加业务逻辑
